🏫 Smart Campus Management System
This is a simple web application built with Python and Flask to manage campus records and view student performance data.

🌐 Live Website Link
Click the link below to open the live interactive project:
🔗 https://my-campus-project-uvk-m09.vercel.app/

✨ Features (3)
1. Student Performance: Reads and displays student scores from a data file.
2. Academic Profiles: Shows real-time text updates for school records.
3. Easy Navigation: Features a clean web layout with intuitive pages.

📁 Project Files (6)
1. smartcampapp.py — The main Python file that runs the website server.
2. student_performance.csv — The data file containing student scores.
3. academic_records.txt — The file with school tracking records.
4. templates/base.html — The visual layout and design structure of the website.
5. requirements.txt — Tells the server which Python libraries to install.
6. vercel.json — Configuration file required to host the website online.
